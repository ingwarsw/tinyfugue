MSDP

MSDP (Mud Server Data Protocol) lets a server send structured data (such as health, room, and opponent information) to the client, and lets the client request which variables the server should report. See the MSDP specification.

MSDP must be compiled in (--enable-msdp) and enabled at runtime with:

/set msdp on

The setting is read when a connection negotiates telnet options, so set it before connecting (or reconnect after setting it). When enabled, tf asks the server to turn on MSDP.

Sending MSDP commands

Use the msdp() function. Its argument is a command in a simple, human readable syntax; the optional second argument selects a world (the current world is used by default). Values assigned to a variable use '=', tables use [ ], and arrays use { }: 

  /test msdp("LIST=COMMANDS")
  /test msdp("SEND=ROOM_VNUM")
  /test msdp("REPORT={ ROOM_VNUM ROOM_NAME HEALTH }")
  /test msdp("UNREPORT=HEALTH")

For convenience you can wrap the function in a command: 

  /def msdp = /test msdp({*})

after which you can simply type, e.g.: 

  /msdp REPORT={ ROOM_VNUM ROOM_NAME }

Receiving MSDP data

Incoming data is delivered to the MSDP hook (no variables are set automatically). The hook text is the decoded data in the same syntax accepted by msdp(), for example: 

  ROOM_VNUM=1234
  COMMANDS= { LIST REPORT RESET SEND UNREPORT }
  ROOM= [ VNUM=1234 NAME=The void EXITS= [ n=1235 ] ]

The structure is conveyed by the [ ] { } and = markers. Scalar values are passed through as-is, without quoting or escaping, so a value that itself contains spaces or these characters is not self-delimiting; parse the markers if you need the exact structure.

A simple way to see everything the server sends: 

  /def -h"MSDP *" msdp_show = /echo -- MSDP: %*

To capture a single value into a variable: 

  /def -msimple -h'MSDP ROOM_VNUM=*' = /set vnum=%{P1}

then use it normally: 

  /echo You are in room vnum=%vnum

Discovering variables

Ask the server what it supports: 

  /test msdp("LIST=REPORTABLE_VARIABLES")

and watch the MSDP hook for the REPORTABLE_VARIABLES array. Other useful lists include CONFIGURABLE_VARIABLES, SENDABLE_VARIABLES, and REPORTED_VARIABLES.
